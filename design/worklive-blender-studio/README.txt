WORKLIVE — THE LOFT / DISCONTINUED VISUAL STUDY

The user rejected this prototype's computing cost and uneven motion on 2026-09-30.
Kept for reference; do not integrate it into Worklive as a finished visual system.
All background Blender jobs have been stopped.

This folder contains an isolated browser scene, original Blender-authored models,
an editable Worklive Studio.blend, and offline Cycles lighting-reference images.
Activities and monitor contents are illustrative. There are no real agent runs,
subscription calls, external model services, or accesses to Worklive user data.
Provider colors remain Codex teal #2D9D8F and Claude terracotta #D97757.

The viewer defaults to a lighter mode. Initial mode verification still measured
one sample of 26 rendered FPS against a 30 FPS at-rest target, with 713,735
triangles and 199 draw calls. This is not proof of acceptable performance.
Subsequent cached-shadow and lazy-postprocessing edits passed syntax checks only.
The partial assets/fast directory is not used by the viewer; the room optimization
was stopped before completion. Full asset export and .blend/render versions can
differ because the final regeneration was interrupted. Do not treat them as a
validated release bundle.

Main authoring source is preserved in work/blender-studio/build_studio.py under
the workspace root; app-before-performance.js preserves the original viewer.
The real Worklive app and Claude Code's visual experiments were not changed.
Engine research and source links are recorded in the shared PROGRESS.md.
