A SMALL, MEASURABLE EXPERIMENT

A lively office.
A lighter footprint.

Twenty original, simple 3D characters. Shared geometry, one light, no real-time shadows or post-processing. Provider shirt colors stay fixed.

The optional browser demo opens two fresh Chrome pages on public documentation websites. They appear on the desk screens and can be enlarged. Browsing is scripted; there are no model calls, credentials, personal browser profiles, saved tasks or memories.

Idle screens do not capture frames. Hidden office rendering pauses, and live browser capture stops when this page is hidden. Closing the demo releases its browser.

This is a browser prototype, not a replacement for the installed Worklive app. FPS is not a measure of total Mac CPU, GPU or memory use.
